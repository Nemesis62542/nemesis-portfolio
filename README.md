# Nemesis Portfolio

ゲームクリエイター Nemesis のポートフォリオサイト。

公開URL: https://nemesis62542.github.io/nemesis-portfolio/

## Run Locally

**Prerequisites:** Node.js

1. Install dependencies:
   `npm install`
2. Run the app:
   `npm run dev`

## Deploy

`npm run build` の後、`npm run deploy` で GitHub Pages に公開します。
